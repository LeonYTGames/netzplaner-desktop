Help & Shortcuts

Netzplaner is fully manual. Values like FAZ, FEZ, SAZ, SEZ, FP and GP are never calculated automatically. Connections are purely visual.

Shortcuts

NCreate new node
EEnter connection mode
Delete / BackspaceDelete selected node
EscapeExit connection mode / clear selection
Ctrl/Cmd + ZUndo
Ctrl/Cmd + YRedo
Ctrl/Cmd + Shift + ZRedo
Ctrl/Cmd + SSave project (choose location on first save)
Ctrl/Cmd + OImport project
FFit network plan to view
MToggle minify
+ / -Change zoom

Usage

Nodes can be moved by drag and drop. If the grid is active and 'Snap to grid' is enabled, positions snap to grid points. For connections, activate Connection first, then click the start and target nodes.
