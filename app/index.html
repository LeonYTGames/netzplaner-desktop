Help & Shortcuts

Netzplaner is fully manual. Values like FAZ, FEZ, SAZ, SEZ, FP and GP are never calculated automatically. Connections are purely visual.

Usage

Nodes can be moved by drag and drop. If the grid is active and 'Snap to grid' is enabled, positions snap to grid points. Hold Shift, Ctrl or Cmd while clicking to select several nodes, or Shift-drag on the canvas to draw a selection box. Dragging one selected node moves the whole selection, and inspector changes apply to every selected node. For connections, activate Connection first, then click the start and target nodes. If several nodes are selected, click the target node to connect each selected node to it. Auto-sort arranges the nodes into columns that follow their connections; one undo step restores the previous positions.
